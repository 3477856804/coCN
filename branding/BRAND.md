# coCN · 品牌视觉规范

> 一门用 C 实现的中文编程语言 —— 让代码，开口说中文。

---

## 一句话定位

**让代码，开口说中文。**
一头龙穿过无限循环，把东方血脉写进每一条 `co` 指令。

## Slogan（可用组合）

| 场景 | 文案 |
|------|------|
| 主 Slogan | **让代码，开口说中文。** |
| 技术向 | 中文即代码，无限即可能。 |
| 情感向 | 母语写万物，龙魂永不停。 |
| 极简 | ∞ · 中文编程，无限可能 |

## 品牌符号叙事

Logo 由**龙头**与**无限符号(∞)**交织而成：
- 龙头向右昂首，象征向前、进取、东方血脉与「黑客精神」；
- ∞ 环形既是无限递归、无限可能，也如盘踞的龙身；
- 环带上刻着编程语法符号（`<O> <C> N C LC7 >>> [ ]`），呼应 C 语言基因。

## 色彩规范

| 色名 | 色值 | 用途 |
|------|------|------|
| 曜黑 | `#0F100B` | 主填充、正文深色背景 |
| 焰红 | `#E4002B`（以 Logo 实物红为准） | 强调、点睛、CTA、警示 |
| 素白 | `#FFFFFF` | 背景、负空间、浅色字 |
| 灰烬 | `#6B6F76` | 次级文字、说明 |

- 主色占比建议：黑 65%（背景/主体）、红 20%（强调）、白 15%（留白）。
- 深色背景场景优先用透明版 Logo（`coCN-logo-transparent.png`）。

## 使用原则

1. 保持黑白红三色，不改色、不添加渐变与投影（实物即规范）。
2. 数字端图标最小 48px，保证符号可辨识。
3. 深色底用透明版，浅色底/文档用实心版。
4. 不可拉伸变形、不可裁切 L 型环绕结构、不可替换红色点睛。
