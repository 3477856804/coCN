# coCN 各平台安装方式

> 命令名：`coCN`。运行：`coCN 程序.co`；`coCN --编译 程序.co 程序` 可生成独立二进制。

## Windows

```powershell
# 免安装单文件（PowerShell 直接下）
irm https://github.com/3477856804/coCN/releases/download/v0.0.1/coCN-windows-x86_64.exe -o coCN.exe

# scoop（需先安装 Scoop）
scoop bucket add cocn <fork:owner>       # 由 bucket 仓库决定
scoop install cocn/coCN
# 或（经 Scoop 主 bucket 收录后）
scoop install coCN

# winget
winget install --id coCN.coCN
```

## macOS

```bash
# Homebrew（自建 tap，立即可用）
brew tap 3477856804/homebrew-cocn
brew install cocn
# 或直接 URL 装
brew install https://raw.githubusercontent.com/3477856804/coCN/master/Formula/coCN.rb

# 一键脚本（预编译二进制优先）
curl -fsSL https://gitee.com/COSMOnb666/coCN/raw/master/install.sh | bash
```

## Linux

```bash
# 任意发行版：一键脚本（预编译优先，回退源码编译）
curl -fsSL https://gitee.com/COSMOnb666/coCN/raw/master/install.sh | bash

# Arch / Manjaro（AUR，收录后）
yay -S cocn        # 或 paru -S cocn
```

## FreeBSD / Docker 等

```bash
# 源码编译（仅需 gcc + make）
git clone https://gitee.com/COSMOnb666/coCN.git && cd coCN && make && sudo install -m755 co /usr/local/bin/coCN
```

## 通用二进制

所有 `v*` tag 由 GitHub Actions 构建 5 种预编译二进制（Linux x86_64/aarch64、macOS
x86_64/arm64、Windows x86_64），挂到 GitHub 与 Gitee 的该 tag Release 下：
`coCN-{linux|darwin|windows}-{x86_64|aarch64|arm64}[.exe]`。
