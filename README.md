# coCN · 中文编程语言（面向模型开发）

`coCN` 是一门用 C 实现的中文编程语言（`co.c` 单文件解释器），目标是**用中文语法更直观地开发机器学习模型**。
语言内置张量（Tensor）类型与**自动求导（autograd）**引擎，你可以用接近伪代码的中文写出可训练的神经网络。

> 定位说明：co 胜在「语法直观、零依赖、单文件可编译」，适合教学、原型验证与中文开发者快速建模；
> 计算性能不及 PyTorch/C 级别（树遍历解释执行），但矩阵/梯度算子均为原生 C 实现，小规模模型训练足够流畅。

---

## 1. 构建与运行

```bash
make            # 编译生成 ./co
make test       # 运行 examples/ 下全部示例
./co 例子/异或网络.co
```

依赖：仅 `gcc` 与标准数学库（`-lm`）。

## 2. 语言基础

| 用途 | 关键字 | 示例 |
|------|--------|------|
| 变量 / 常量 | `让` `常量` | `让 x = 3` |
| 函数 | `函数` `返回` `结束` | `函数 平方(a) 返回 a*a 结束` |
| 输出 | `输出`（无括号，逗号分隔） | `输出 "结果=", x` |
| 条件 | `如果` `则` `否则如果` `否则` `结束` | `如果 a > b 则 ... 否则 ... 结束` |
| 当循环 | `当` `循环` `结束` | `当 条件 循环 ... 结束` |
| 计数循环 | `对于` `从` `到` `步长` `循环` `结束` | `对于 i 从 1 到 10 循环 ... 结束` |
| 跳出 / 继续 | `跳出` `继续` | |
| 逻辑 | `且` `或` `非` | |
| 注释 | `#` | `# 这是注释` |

> 注意：`输出` 是特例，语法为 `输出 表达式1, 表达式2`（**没有括号**）；其余函数调用均用括号，如 `西格莫德(z)`。

## 3. 张量与模型开发 API

### 3.1 构造与属性

| 函数 | 作用 | 示例 |
|------|------|------|
| `张量(...)` | 构造张量：嵌套列表/一维数字列表/单个整数/两个整数 | `张量([[1,2],[3,4]])` |
| `全零(形状)` | 全 0 张量 | `全零([2,3])` |
| `全一(形状)` | 全 1 张量 | `全一([2,3])` |
| `随机张量(形状, 下限, 上限)` | 均匀分布随机 | `随机张量([2,2], -1, 1)` |
| `高斯随机(形状, 均值, 标准差)` | 正态分布随机（参数初始化首选） | `高斯随机([4,4], 0, 0.1)` |
| `形状(t)` | 返回形状列表 | `形状(a)` |
| `重塑(t, 形状)` | 改变形状（元素总数不变） | `重塑(a, [6])` |
| `需梯度(t)` | 标记该张量需要梯度（参与反向传播） | `需梯度(高斯随机([2,1],0,1))` |

### 3.2 运算（均支持自动求导）

| 函数 / 运算符 | 作用 |
|------|------|
| `a + b` `-` `*` `/` | 元素级运算，**支持广播**（如 `[4,1] + [1,1]`） |
| `矩阵乘(a, b)` | 二维矩阵乘法 |
| `转置(t)` | 矩阵转置 |
| `求和(t)` `均值(t)` | 全部元素求和 / 均值（得到标量） |
| `指数(t)` `对数(t)` | 逐元素 exp / log |
| `西格莫德(t)` | Sigmoid |
| `双曲正切(t)` | Tanh |
| `线性整流(t)` | ReLU |
| `柔性最大值(t)` | Softmax（按行） |
| `取(t, i)` `取(t, i, j)` | 读元素（返回浮点） |
| `置(t, i, v)` `置(t, i, j, v)` | 原地写入元素 |

### 3.3 损失、求导与优化

| 函数 | 作用 |
|------|------|
| `均方误差(预测, 目标)` | MSE 损失（返回标量张量） |
| `交叉熵(概率, 标签)` | 已做 softmax 的概率上的交叉熵 |
| `对数交叉熵(logits, 标签)` | 数值稳定的「softmax + 交叉熵」 |
| `反向(损失)` | 对损失张量触发**反向传播**，自动填充各参数梯度 |
| `优化(学习率, [参数...])` | SGD 更新参数（数据 -= 学习率*梯度）并清零梯度 |

## 4. 训练套路（三步法）

```co
让 w = 需梯度(高斯随机([输入, 输出], 0, 0.1))   # 1) 参数需梯度
...
让 损失 = 均方误差(预测, 目标)                  # 2) 前向得到标量损失
反向(损失)                                      # 3) 自动求导
优化(学习率, [w, b])                            #    更新并清零梯度
```

`反向(损失)` 会从损失标量沿计算图反推，自动求出所有 `需梯度` 参数的梯度；
`优化` 按 SGD 规则更新这些参数。整个过程**无需手写反向公式**。

## 5. 完整示例：异或网络

```co
让 学习率 = 0.5
让 隐藏 = 4
让 x = 张量([[0,0],[0,1],[1,0],[1,1]])
让 y = 张量([[0],[1],[1],[0]])

让 w1 = 需梯度(高斯随机([2, 隐藏], 0, 1))
让 b1 = 需梯度(全零([1, 隐藏]))
让 w2 = 需梯度(高斯随机([隐藏, 1], 0, 1))
让 b2 = 需梯度(全零([1, 1]))

函数 前向(输入)
    让 a1 = 双曲正切(矩阵乘(输入, w1) + b1)
    返回 西格莫德(矩阵乘(a1, w2) + b2)
结束

对于 轮 从 0 到 5000 循环
    让 损失 = 均方误差(前向(x), y)
    反向(损失)
    优化(学习率, [w1, b1, w2, b2])
结束
输出 前向(x)   # 输出接近 [0, 1, 1, 0]
```

更多可运行示例见 `例子/` 目录：`张量演示.co` `线性回归.co` `异或网络.co` `分类演示.co`。

## 6. 与 Python 的对比

| 维度 | co（中文） | Python + numpy/PyTorch |
|------|-----------|------------------------|
| 语法 | 全中文关键字，贴近自然语言 | 英文 |
| 依赖 | 单文件 C，零依赖 | 需安装 numpy / torch |
| 张量 | 内置 `张量` 类型 | `np.array` / `torch.Tensor` |
| 自动求导 | 内置 `反向()` | torch 内置 `loss.backward()` |
| 入门门槛 | 中文母语者极友好 | 需英文 + 库 API |
| 性能 | 解释执行，适合小模型/教学 | 编译/CUDA，适合大规模训练 |

**结论**：co 不是要取代 PyTorch，而是提供一种「中文即可建模、零依赖即跑」的轻量选择，
特别适合中文教学、算法原型与不想被英文 API 与庞杂依赖劝退的场景。
