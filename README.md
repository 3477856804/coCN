# coCN · 中文编程语言

`coCN` 是一门用 C 实现的中文编程语言（`co.c` 单文件解释器，约 4700 行，零第三方依赖）。
它既是一门**通用编程语言**（静态类型标注、模块、模式匹配、推导式、真并发、文件 IO、高阶函数），
也内置**张量类型与自动求导引擎**，可以用接近伪代码的中文写出可训练的神经网络。

> 设计取向：语义正确性优先于特性数量。任何"看起来能跑但结果是错的"行为都按缺陷处理——
> 例如 `"abc" == "xyz"` 必须为 `假`（而不是被当成字符串拼接后恒为真），`y = -x` 必须不改动 `x`。

---

## 1. 构建与测试

```bash
make              # 编译生成 ./co
make test         # 功能套件 + 错误路径 + 全部例子（一键回归）
make asan         # ASan + UBSan：要求零泄漏、零未定义行为
make tsan         # ThreadSanitizer：要求并发用例零数据竞争
make check        # 提交门禁 = test + asan + tsan
./co 例子/异或网络.co
```

依赖：仅 `gcc`、`-lm`、`-lpthread`。

## 2. 数据类型

| 类型 | 标注关键字 | 字面量 | 说明 |
|------|-----------|--------|------|
| 整数 | `整数` | `42` `-7` | 64 位 |
| 浮点 | `浮点` | `3.14` | 双精度；整数可隐式加宽为浮点 |
| 布尔 | `布尔` | `真` `假` | **独立一等类型**，打印为 `真`/`假`，不是 `0/1` 别名 |
| 字符串 | `字符串` | `"你好"` | UTF-8，**按字符**索引与取长度 |
| 列表 | `列表` | `[1, 2, 3]` | 可异构、可嵌套 |
| 字典 | `字典` | `{"键": 值}` | 字符串键 |
| 张量 | `张量` | `张量([[1,2],[3,4]])` | 支持广播与自动求导 |
| 函数值 | `函数值` | 函数名本身 | 可作参数传递（高阶函数） |
| 数字 | `数字` | — | 整数或浮点（标注用） |
| 任意 | `任意` | — | 关闭该处类型检查 |
| 空 | `空` | — | 无值 |

类型标注是**渐进式**的：不写就是动态，写了就在赋值/传参/返回处强制检查。

```co
整数 n = 10
布尔 开关 = 真
函数 安全除(浮点 a, 浮点 b) -> 浮点
    若 b == 0.0 返回 0.0
    返回 a / b
结束
```

## 3. 语法速查

| 用途 | 关键字 | 示例 |
|------|--------|------|
| 变量 / 常量 | `让` `变量` `常量` | `让 x = 3` |
| 函数 | `函数` `返回` `结束` `->` | `函数 平方(整数 a) -> 整数 返回 a*a 结束` |
| 输出 | `输出`（无括号，逗号分隔） | `输出 "结果=", x` |
| 条件 | `如果`/`若` `则`/`那么` `否则如果`/`否则若` `否则` `结束` | `若 a > b 那么 ... 否则 ... 结束` |
| 当循环 | `当` `循环` `结束` | `当 条件 循环 ... 结束` |
| 计数循环 | `对于` `从` `到` `步长` `循环` `结束` | `对于 i 从 1 到 10 步长 2 循环 ... 结束` |
| 跳出 / 继续 | `跳出` `继续` | `继续` 只跳过本次迭代 |
| 逻辑 | `且` `或` `非` | 短路求值，结果为布尔 |
| 模块 | `导入` | `导入 "标准库"` |
| 模式匹配 | `匹配` `是`/`情况` `默认` `结束` | 见 §3.4 |
| 推导式 | `对于` `于`/`在` `如果`/`若` | 见 §3.3 |
| 并发 | `并发` `等待` | 见 §3.5 |
| 注释 | `#` | `# 这是注释` |

> `输出` 是特例：`输出 表达式1, 表达式2`（**无括号**）。其余函数调用都用括号。

### 3.1 运算符

| 运算符 | 语义 |
|--------|------|
| `+` `-` `*` | 数值算术；`+` 还可用于**字符串拼接**与**列表拼接** |
| `/` | **真除法**：`3 / 2` = `1.5`；除零报错 |
| `//` | 向下取整整除：`7 // 2` = `3`，`-7 // 2` = `-4` |
| `%` | 取模（支持浮点），除零报错 |
| `==` `!=` | **结构化判等**：数值跨类型、字符串逐字节、列表/字典/张量递归比较 |
| `<` `>` `<=` `>=` | 同类可比：数值之间、字符串字典序、列表字典序；跨类型比较**报错**而非静默出错 |
| `-x` | 取负，**返回新值**，绝不修改源变量或容器元素 |
| `x[i]` | 索引：列表/字符串支持**负索引**（`-1` 为末位）；字符串按字符切分不会切碎汉字 |

**比较结果一律是布尔**。字符串只接受 `+` 拼接，`"a" - 1` 这类会明确报错。

### 3.2 字符串（UTF-8 感知）

```co
断言相等(长度("你好世界"), 4)          # 按字符计数，不是字节
断言相等("你好世界"[0], "你")           # 按字符索引
断言相等("你好世界"[-1], "界")          # 负索引
断言相等(反转("你好"), "好你")
断言相等(分割("甲、乙、丙", "、"), ["甲", "乙", "丙"])   # 多字节分隔符
```

### 3.3 推导式

```co
列表 平方表 = [x * x 对于 x 在 范围(1, 6)]                    # [1,4,9,16,25]
列表 偶数表 = [x 对于 x 在 范围(1, 11) 如果 x % 2 == 0]        # [2,4,6,8,10]
字典 词长 = {w: 长度(w) 对于 w 在 ["苹果", "西瓜"]}            # 单变量形式
字典 反表 = {v: k 对于 k, v 于 {"甲": "1"}}                   # 键值双变量形式
```

`于` 与 `在` 互为别名，`如果` 与 `若` 互为别名。

### 3.4 模式匹配

```co
匹配 状态码
    情况 1: 输出 "就绪"
    情况 2: 输出 "运行中"
    默认:  输出 "未知"
结束
```

`是` 与 `情况` 互为别名。模式支持整数/浮点/字符串/**布尔**/**列表**/**字典**（结构化判等）。

### 3.5 并发（真线程）

```co
句柄1 = 并发 部分和(0, 1000000)
句柄2 = 并发 部分和(1000001, 2000000)
整数 总 = 等待 句柄1 + 等待 句柄2      # 等待是一元运算符，优先级高于 +
```

`并发 表达式` 创建 pthread 并立即返回任务句柄；`等待 句柄` join 并取回结果。
`并发`/`等待` 是**一元前缀运算符**，只吃紧跟的一个操作数——想并发整个表达式请显式加括号：`并发 (甲 + 乙)`。
引用计数为原子操作，控制流标志为线程局部，共享环境加锁，`make tsan` 保证零数据竞争。

### 3.6 模块与函数前置引用

```co
导入 "标准库"            # 加载同目录 标准库.co，其顶层函数并入当前作用域
输出 是三倍(9)           # 函数可在定义之前调用（顶层函数会被提升）
函数 是三倍(整数 x) -> 布尔
    返回 x % 3 == 0
结束
```

### 4.7 张量与自动求导

**构造与属性**

| 函数 | 作用 |
|------|------|
| `张量(...)` | 嵌套列表 / 一维列表 / 单个整数 / 两个整数 |
| `全零(形状)` `全一(形状)` | 常量张量 |
| `随机张量(形状, 下限, 上限)` | 均匀分布 |
| `高斯随机(形状, 均值, 标准差)` | 正态分布（参数初始化首选） |
| `形状(t)` `重塑(t, 形状)` | 形状查询与变形 |
| `需梯度(t)` | 标记参与反向传播 |

**运算（均可求导）**

`a + b - * /`（**支持广播**）`矩阵乘` `转置` `求和` `均值` `指数` `对数`
`西格莫德` `双曲正切` `线性整流` `柔性最大值` `取(t,i[,j])` `置(t,i[,j],v)`

> `求和`/`均值` 是多态的：作用于张量得到标量张量，作用于列表得到数值。

**损失与优化**

`均方误差(预测, 目标)` `交叉熵(概率, 标签)` `对数交叉熵(logits, 标签)`
`反向(损失)` `优化(学习率, [参数...])`

## 5. 训练套路（三步法）

```co
让 w = 需梯度(高斯随机([输入, 输出], 0, 0.1))   # 1) 参数需梯度
让 损失 = 均方误差(预测, 目标)                  # 2) 前向得到标量损失
反向(损失)                                      # 3) 自动求导
优化(学习率, [w, b])                            #    更新并清零梯度
```

`反向(损失)` 从损失标量沿计算图反推，自动求出所有 `需梯度` 参数的梯度，**无需手写反向公式**。

### 完整示例：异或网络

```co
让 学习率 = 0.5
让 x = 张量([[0,0],[0,1],[1,0],[1,1]])
让 y = 张量([[0],[1],[1],[0]])

让 w1 = 需梯度(高斯随机([2, 4], 0, 1))
让 b1 = 需梯度(全零([1, 4]))
让 w2 = 需梯度(高斯随机([4, 1], 0, 1))
让 b2 = 需梯度(全零([1, 1]))

函数 前向(输入)
    让 a1 = 双曲正切(矩阵乘(输入, w1) + b1)
    返回 西格莫德(矩阵乘(a1, w2) + b2)
结束

对于 轮 从 0 到 5000 循环
    让 损失 = 均方误差(前向(x), y)
    反向(损失)
    优化(学习率, [w1, b1, w2, b2])
结束
输出 前向(x)   # 接近 [0, 1, 1, 0]
```

## 7. 错误诊断

运行时错误一律带行列号与中文说明，绝不静默出错：

```
运行时错误 (第2行,13列): 无法比较大小: 字符串 < 整数
运行时错误 (第2行,11列): 字符串只支持 + 拼接，不支持 -（字符串 - 整数）
运行时错误 (第2行,11列): 递归过深（超过 3000 层），请检查是否存在无限递归
运行时错误 (第2行,9列): 列表索引越界: 10 (列表长度 3)
```

无限递归会被转成干净的错误信息而不是段错误（栈深度上限 3000 层）。

## 8. 与 Python 的对比

| 维度 | coCN | Python + numpy/PyTorch |
|------|------|------------------------|
| 语法 | 全中文关键字，贴近自然语言 | 英文 |
| 依赖 | 单文件 C，零依赖 | 需安装 numpy / torch |
| 类型 | 渐进式静态标注，运行时强制检查 | 注解不强制 |
| 张量 | 内置 `张量` + `反向()` 自动求导 | `torch.Tensor` + `loss.backward()` |
| 并发 | `并发`/`等待` 真线程，无 GIL | 受 GIL 限制，需多进程 |
| 质量门禁 | ASan/UBSan/TSan 零容忍 | — |
| 性能 | 树遍历解释，适合小模型/教学 | 编译/CUDA，适合大规模训练 |

**结论**：coCN 不是要取代 PyTorch，而是提供一种「中文即可编程与建模、零依赖即跑」的轻量选择，
特别适合中文教学、算法原型，以及不想被英文 API 与庞杂依赖劝退的场景。
